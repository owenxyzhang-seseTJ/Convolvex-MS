# Web DEMS 工作台

启动本地服务后，打开项目配置的 Web 地址。在工作台导入数据、添加候选组分或导入响应矩阵，再开始分析。界面保留原有的一维信号等任务；DEMS 使用原生多通道算子，不将多通道数据压成单条曲线。

## 数据导入

支持 CSV、TSV、TXT、XLSX、原生数据 JSON 和项目 JSON。自动预览列名、单位与工作表，也可展开「检查列映射与单位」手动调整。

典型表头：

```text
time_s,mz_28 (pA),mz_44 (nA),potential_V,current_mA
```

- 时间支持 s、ms、min，统一换算为秒。m/z 信号支持按列识别 A / mA / µA / nA / pA，统一为 A；相对值、counts、Pa、mbar 保留原物理单位。
- 电位列支持 `potential_V`、`voltage_mV`、`Ewe/V`、`Ewe/mV` 等，也可手动选择列与 V / mV 单位。电流列支持 `current_A`、`current_mA`、`I/mA` 等。
- 缺测 MS 数值保存有效性掩码，图上断线；电位与 EC 电流要求完整有限数值。重复时间、非数值和公式会被拒绝。
- 非均匀 MS 时间保留；谱分离可以使用，基于 FFT 的传输反演要求显式均匀时间网格。
- XLSX 默认选择有效数据工作表，不执行单元格公式。单文件最大 20 MB。

「导入 LSV / EC」可导入独立的时间—电位／电流文件；它保留自己的 EC 时间网格。支持 `Ewe/V`、`<I>/mA` 及电流密度列；电流密度须提供电极面积，明确换算为 A。没有时间列时，必须给出扫描速率（mV/s）和 LSV 起始时刻，仅对恒速、严格单向扫描按 `t = t₀ + |E − E₀| / |v|` 重建时间。往返扫描、重复电位和恒电位段不能用此式猜测时间，应导入实测时间。

两个文件需使用相同时间起点，或在「EC 时钟偏移 / s」中显式给出时钟偏移。正偏移表示将 EC 时间记录向后移动。另有独立的「传输纯延迟 / s」，将检测器信号映射到 `t_electrode = t_MS − τ`。纯延迟适用于给定的谱分离曲线；已使用传输核联合反演时不重复施加。只在 EC 实测支撑范围内线性插值用于显示与查询，不外推，也不改写原始 EC 数组。MS 积分窗口为 `[a,b]` 时，纯延迟对应的 EC 分母窗口为 `[a−τ,b−τ]`，EC 总电荷仍在原始 EC 网格上计算；超出实测范围时不生成该分母。

原生 `web-ms-1.0` 项目包含 `dataset`、`analysis` 及可选的 `dems` 设置。`dataset` 使用 `ms-1.0` 的字段，并在 Web 路径支持 `potential_V`；它与 `ec_time_s` 对齐。独立 EC 时间轴、多通道掩码和仪器信息可通过 JSON 完整保存。项目 JSON 可往返保存候选响应、传输核、DEMS 设置及用户输入的标定。

## 标准图谱库

侧栏「基准」已由「标准图谱库」替代，分为 CO₂RR、NORR、碳氮耦合、同位素示踪、常见催化。碳氮耦合分类包括尿素、甲酰胺、乙酰胺、甲胺、乙胺、二甲胺、三甲胺、乙腈、甘氨酸、乙醇胺与草酰胺。条目是按需检索入口；点击后才从 NIST Chemistry WebBook SRD 69 获取公开 EI 峰表，缓存成功响应并保留原始条目链接、名称、CAS、来源与获取时间。低挥发、高极性产物的标准 EI 谱不代表常规 DEMS 能直接检测；检测和采样条件需要另行确认，衍生化产物的谱应独立导入。

这不是完整的商业 NIST 数据库。部分同位素只有物种条目而没有公开 EI 峰表；界面会显示未公开并清除旧图谱，不用母体平移谱代替。可导入本地 JCAMP-DX 显式 `(XY..XY)` 峰表、m/z–intensity CSV，或已导出的参考谱 JSON。本地导入按本地来源标记，不自动继承 NIST 身份。

候选响应在监测通道 ±0.25 m/z 范围内匹配峰，每列按所选通道中的最大响应归一为 1，并记录参考 m/z。复杂体系通过多个候选谱与多个监测通道共同分离。单个 m/z 可能对应多种物质；相对碎片谱不自动确认身份，也不提供本机绝对灵敏度。

标准谱优先保留文件中的明确物质名称和 CAS；已知物质可显示中文名与分子式。候选列表、分量选择、图例、极化曲线、报告与 CSV 使用同一名称。本地 CSV 只有峰表时，导入前需填写物质名称；图谱库内也可修改「候选组分名称」。不从碎片峰猜测身份，也不将 A/B/C 直接重命名为未经验证的物质。历史数学示例中的 ABC 在添加实际标准谱时会移除，避免混在实际候选集合中。

## DEMS 与 LSV 的处理流程

先导入 DEMS 时间序列，再导入同时记录的 LSV（同一文件有 E/I 时自动识别），随后按以下顺序处理：

1. 核对单位、时间起点及扫描方向，分开设置时钟偏移和已知传输延迟。
2. 需要扣背景时，在左侧高级模型设置中勾选「按空白区间逐通道扣背景」，填写空白窗口并选择常数背景或线性漂移。只在明确的空白样本上拟合背景，逐通道先扣背景再按标准谱解混；负残差信号保留。修改后重新运行分析。原始信号不覆盖，结果含独立背景数组与空白点数。
3. 从标准图谱库添加有具体名称的候选物质，检查碎片干扰与响应矩阵的可分辨性；按需提供传输核。
4. 右侧联合分析并列查看原始 EC 网格上的 LSV 总电流、所选物质的极化曲线、质谱伏安曲线与 Tafel。电极面积提供后，显示电流密度；未标定时，组分曲线保留响应等效信号单位。
5. 使用本机有效灵敏度和反应电子数换算分电流、产量与区间电荷。只有适用的传输校正或经确认的稳态条件下，才输出瞬时 FE；单独的纯延迟平移不能消除传输展宽。

这一组织顺序依据 DEMS 的校准与电位关联工作方式，并结合动态传输反演的适用边界；它是本工作台的实施流程，不把所有实验自动视为同一种标准协议。方法依据：Baltruschat, *Differential electrochemical mass spectrometry*, JASMS **15**, 1693–1706 (2004), [DOI](https://doi.org/10.1016/j.jasms.2004.09.011)；Krempl et al., *Dynamic Interfacial Reaction Rates from Electrochemistry–Mass Spectrometry*, Analytical Chemistry **93**, 7022–7028 (2021), [DOI](https://doi.org/10.1021/acs.analchem.1c00110)，[作者机构说明](https://v-sustain.dtu.dk/publications/2021/05/dynamic-interfacial-reaction-rates-from-electrochemistry-mass-spectrometry)。标定边界另参考 [On the accurate calibration of differential electrochemical mass spectrometry](https://doi.org/10.1016/j.coelec.2023.101393)。

## DEMS 快速处理

右侧切换「DEMS 快速处理」，选择起止时间、m/z 和分析组分，点击「更新分析」。高级参数默认收起。

- **时间／电位／电流查询**：时间查询返回最近的有效 MS 实测点及实际时间；电位和电流查询按允许偏差返回全部匹配记录。重复经过同一电位的记录分段列出，避免隐藏不同扫描支路。
- **复杂体系贡献**：列出所选 m/z 下各候选物质的相对响应、该通道拟合贡献及源组分信号。对于谱–时间联合反演，该通道贡献使用源信号经过对应传输核后的值，而非直接以源项冒充检测器信号。
- **信号时间斜率**：区间内有效信号对时间做线性回归，单位为信号单位 / s。它与 Tafel 斜率分别报告。
- **区间积分**：按分段线性曲线精确裁切时间端点；缺测间隙不跨越，只累计两端均有效的相邻线段并报告覆盖率。离子检测器的 C 与反应转化电荷分别显示。

### Tafel

拟合形式为 `E = a + b·log10(I)`；提供平衡电位时，纵轴为 `η = E − E_eq`。可输入未补偿电阻，按带符号原始电流计算 `E_corrected = E − I_EC·R_u`。电位范围以校正后的 E 选择，平衡电位只改变纵轴原点。

仅在所选时间／电位范围内，按电位等宽分箱，先平均正电流或正信号再取 log₁₀，用普通最小二乘求斜率。返回带符号斜率、绝对斜率（mV/dec）、回归标准误、R²、分箱点数和实际拟合点。负值与零值不取绝对值、不截断为小正数；可显式输入基线和离子极性。电位的小幅采集噪声被容许，明显往返扫描需要通过时间范围选择单个支路。

未标定或未确认稳态时，界面标为「信号–电位表观斜率」。只有所选组分具备适用标定、数值收敛、响应可分辨，且用户确认稳态和动力学控制区时，才标为「产物 Tafel 曲线」。电极面积可用于分电流密度。稳态、iR 处理、传质控制和电位参比需要实验判断，不自动确认；回归标准误不包含这些系统误差。

### 物质转化电荷

本机有效灵敏度定义为 `S = 参考通道等效离子电流 / 产物生成速率`，单位 C/mol，并包含收集效率。对所选分离组分：

```text
r(t) = I_species(t) / S                 [mol/s]
N = ∫ r(t) dt                          [mol]
Q_product = n · F · N                  [C]
I_product(t) = n · F · r(t)             [A]
FE = Q_product / Q_EC,direction
```

`n` 是具体反应路径的电子数，`F = 96485.33212331001 C/mol`。同一个产物在不同反应中可能有不同电子数，软件不按物质名称猜测。EC 分母使用用户选定的阴极或阳极电荷，可能包含电容等非产物贡献；不自动扣除背景，不把总电荷当成纯法拉第电荷。

「所选组分的本机标定」需填入灵敏度、电子数、参考 m/z、记录名称、仪器和实验条件，并确认来自适用的标准实验。记录连同当前监测通道、响应列及传输模型保存在项目中；后端逐项比较这些数值和身份。合成与实验标定不能混用，响应参考系数须为 1，传输核积分须接近 1。未收敛、谱秩不足、共线响应、负源项、缺测或未确认完整区间时，不生成绝对转化电荷。谱分离模式的完整窗口积分依赖收集完整传输响应；瞬时生成速率需要适用的传输校正或稳态。

Web 标定是用户提供的分析输入，不由软件建立标准实验、审核真实性或批准标定，也不更改现有 MCP 私有标定工作流。没有有效标定仍可查看原始 EC 电荷和相对 MS 信号积分。FE 超过 100% 会提示检查并保留计算值。

## 结果与接口

可导出原始 LSV CSV、联合处理 CSV、分析报告 JSON、项目 JSON 和原始拟合结果 JSON。原始 LSV 导出保留 EC 网格、电位、电流与时间来源；联合 CSV 包含 MS 时间、电极时间、原始／背景／校正信号、具体组分名、分电流、条件性瞬时 FE 与区间标记。谱分离的标定速率标为 `transport_filtered_rate_mol_s`，报告中标明 `rate_scope`，避免将传输滤波后的曲线当成瞬时电极通量。界面曲线最多抽取约 3000 点以保持交互速度；回归与积分均使用完整数据。导出处理数据会获取完整分辨率曲线，不沿用显示抽样。滚动条默认透明，滚动时显示，停止约 0.8 秒后隐藏，保留滚动操作。

主要 Web REST 接口：

| 接口 | 功能 |
|---|---|
| `POST /api/v1/import/preview`、`/import/data` | 预览、映射、导入表格 |
| `POST /api/v1/ms/dataset`、`/ms/project/validate` | 校验原生数据与项目 |
| `GET /api/v1/spectra/catalog`、`/spectra/nist?query=...` | 分类检索与官方公开谱 |
| `POST /api/v1/spectra/import`、`/ms/response` | 本地峰表与候选响应 |
| `POST /api/v1/jobs` | 原生 DEMS 异步分析，沿用队列、取消与历史 |
| `POST /api/v1/ms/process` | 电位查询、Tafel、积分与条件性定量 |

`/ms/process` 接收 `dataset`、可选的已完成 `job_id`、`settings` 和显示点数 `trace_points`（默认 3000，上限 200000）。组分计算只读取服务端已完成的拟合结果；客户端不能提交任意源项冒充拟合。提供数据与记录同时使用时，校对质谱时间、通道、信号、掩码、单位、时间起点及合成标记。EC 数据允许补充并保持原始网格。

默认示例用带来源链接的公开 NIST H₂、CO、CO₂ 峰表建立响应矩阵，再单独生成合成信号、传输核与 LSV。候选物质显示氢气、一氧化碳和二氧化碳。真实参考谱与合成实验数据分别标明，不提供默认实验灵敏度；示例不是实验标定或实测性能。
